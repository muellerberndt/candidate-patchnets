# First finite-context search result

The candidate obtains a retained joint model and its answer through the same
exact local factor-conditioning kernel. It passes the small context-switching
probe when its supplied model permits switches. It also executes the three
shared structural challenges, including the four-neuron fly-derived transition
fixture. This is progress toward a reusable component, not a replacement brain.

**Actual belief self-observation is unsupported. Core replacement is not ready;
larger training and scaling remain locked.** No core, shared suite, other search
lane, index or commit was changed by this search. These are local results for
the separate worker responsible for committing the workspace.

## The component and the actual improvement

The persistent model is the joint probability of two unknown binary values,
`A,B`, and a current hidden context, `c`. The answer is the value selected by
that context. Only eight exact probabilities are retained. A new observation
conditions a four-patch cluster tree; the qualified posterior boundary becomes
the next memory. A query uses the same local message equations and preserves
that memory. No gradient or separate conjugate-statistic increment computes
the update.

The observation compiler, chosen model, posterior boundary projection, event
admission and transactional commit remain explicit host operations. The result
does not make them disappear, or establish the full architectural one-rule gate.
The same generic kernel is used for the fly, holonomy and federation tasks, but
those tasks are separately supplied factor problems. They do not yet modify the
stream's contextual knowledge or make an integrated embodied agent.

Only the module's joint boundary and event cursor persist. Its message graph is
built afresh for each event or query; messages are not a continuously running
nervous system. Each individual factor patch does not yet have its own durable
experience record. This tests one retained observer component composed of four
local factors, not the entire proposed hierarchy of persistent observers.

This improves on the earlier scalar accumulating example in a bounded way:
changing regimes no longer have to be forced into a single stationary mean.
Both the switch model and the possible values are supplied. General context
discovery, arbitrary value learning and learned topology are absent.

## Relationships carry information that individual marginals lose

The two constructed joint distributions in the theorem have identical
individual `A`, `B` and `c` marginals but opposite certain answers, -2 and +2.
Removing their joint dependence makes both answers 0. The executable witness
confirms this exactly. These distributions were supplied as fixtures; their
successful representation is not a claim that the stream learned them.

The stream also acquires relevant joint dependence. For h=1/16, the history
`(-2,-2,-2,0)` gives an answer of -1.882594. Replacing its retained distribution
by `P(A,B)P(c)`, preserving the entire parameter joint and the context marginal,
changes the answer to -1.064180. A fresh model observing only 0 answers 0.
The final observation is equally likely under both possible centers. Its
arrival can advance context time, but it leaves `P(A,B)` exactly unchanged.

Context labels remain symmetric: `P(c=0)=P(c=1)=1/2`. The useful information is
in their relationship with the parameters and the public selected value. It
would be incorrect to describe this as recovery of a uniquely named context.
Last-nonzero and decaying-average controls also retain history. The receipt
reports them; the history result does not establish uniqueness or superiority.

## A negative forecasting result, preserved

Each of the 32 binary streams of length five is scored equally. The model sees
only the first four observations and predicts the fifth before it arrives.
Because this exhaustive weighting makes the fifth sign independent of history,
a uniform sign predictor is the appropriate control. Temporal persistence
assumptions can hurt here. Lower values are better in the following table.

| Predictor | h | Mean negative log probability | Mean squared center error |
| --- | --- | ---: | ---: |
| Learned joint | 0 | 2.501146 | 6.499878 |
| Known parameters | 0 | 2.501146 | 6.499878 |
| Learned joint | 1/16 | 1.859374 | 6.851796 |
| Known parameters | 1/16 | 1.795620 | 6.799726 |
| Learned joint | 1/4 | 1.402042 | 5.238120 |
| Known parameters | 1/4 | 1.337208 | 4.974832 |
| Reset parameter prior | all | 1.200025 | 4.000000 |
| Frozen uniform | all | 1.200025 | 4.000000 |
| Last observed value | all | 3.283365 | 8.000000 |

The known-parameter filter and the learner are both worse than the frozen
predictor here. There is no demonstrated general forecasting advantage. This
diagnostic checks causal scoring and exposes model mismatch; it is not an
evaluation sampled from the candidate's own hidden-context model. No setting
was adjusted after these outcomes.

Scores use probability on the declared 17-value observation alphabet. They are
not binary classification cross-entropy. Next-event scores in this lane use
`prediction()`, which advances the declared context transition privately. The
shared battery's `pre_outcome_predictions` records current-state `query()`
outputs before an event; those are not the same forecast contract.

## Resource and biological boundaries

The D3 battery uses 24 zero observations. The largest checkpoints in that
fixture are 152, 155 and 154 bytes for h=0, 1/16 and 1/4. Its symmetric messages
are already settled. This is deliberately a bounded resource check, not a
worst-case rational bit-growth measurement or a model of realistic sensory
traffic. Kernel counters exclude some independent qualification and host work;
the total wall time includes it. The fixed 24-event capacity is a test boundary,
not a production memory solution.

The frozen v1 checkpoint parser is for trusted local fixtures only. Its string
length check does not adequately bound work before `Fraction` conversion:
scientific notation can encode an enormous exponent in a short string. The
audit did not execute a large allocation. A future candidate revision must
reject noncanonical rationals and bound numerator/denominator sizes before
conversion. These saved, small, internally generated checkpoints are unaffected;
the current parser must not be exposed to untrusted input or promoted to core.

The mammal/human constraint informs what comes next: a useful component should
preserve distinct learned relations, resolve incomplete or ambiguous cues using
experience, and expose a meaningful state to other jointly settling observers.
The biological studies motivating those questions are linked in [README.md](README.md).
None identifies this eight-state model with a neuron, hippocampus or cortex.

The fly challenge runs a small transformed fixture derived from four actual
neurons. It is not the full connectome, a test of natural fly behavior, or proof
of preservation of biological dynamics. Imagination, planning, reasoning,
drives, sensorimotor control and recursive belief observation remain separate
requirements; passing scalar memory and structural equations cannot discharge
them.

## Deviations and audit trail

The first main run aborted before producing a scientific receipt: two neutral
observations in a history generated a duplicate assertion name. The original
source is preserved in `history/before-unique-neutral-check.tar.gz`, and
[harness_failure_001.json](history/harness_failure_001.json) records the error.
The correction only included the event index in that assertion name. No trial,
threshold, model setting or result was removed.

Protocol step 4 described a product-of-singletons lesion for actual streams.
The executed stream ablation instead preserves the stronger parameter joint
and cuts only its dependence on context: `P(A,B)P(c)`. Product-of-singletons
lesions ran on the constructed fixtures. This narrower causal intervention is
useful, but is a deviation from that sentence, not an excuse to rewrite the
frozen protocol. Broader suggestions in SKEPTICAL_CONTROLS.md are not all run.

The original `probe.py --verify` compares Python structures, which can treat
`True` as equal to `1`. The new [verify_round.py](verify_round.py) preserves the
original receipt and source while providing strict JSON type comparison,
duplicate-key and nonfinite-value rejection, source checks before and after
execution, and a separate immutable verification receipt. Use that stricter
entry point below. Its six mutation tests reproduce and reject the original
comparison weakness.

The original main receipt hashed its sources only at the end and omitted the
imported `contract.py`. The supplemental verification pins `contract.py` and
checks start/end source equality for its new replay. It does not retroactively
prove full original-run source custody. The separate battery receipts also
record the shared files used by their own runs.

## What this result warrants next

A further small candidate can test learned cross-cue recall: learn associations
between two inputs, withhold one input, and ask whether conditioning on the
other recovers the learned relation. Counterbalance the associations, remove
their dependence while preserving marginals, and compare with latest-value and
lookup controls. This would distinguish acquired relational memory from merely
tracking the most recent center. It has not run in this lane.

The evidence review proposes a particularly small transfer task: two observable
stimuli and four unknown context-by-stimulus response bits. Retaining those
bits with the current context needs only 32 joint states. After learning both
stimuli, infer a context switch from one stimulus and predict the other before
receiving its new-context outcome. Independent-per-stimulus learners, fixed
parameter models and counterbalanced response assignments are necessary
controls. This is a proposed new protocol, not a result or permission to scale.

Actual self-observation needs its own explicit contract: another patch must
read a quantity of the current belief, feed back a constraint, and settle
together with the patches it reads. A latent world-state variable does not meet
that requirement. No benchmark gain or layer count can substitute for this
mechanism test. The next candidate must state both its readback and its feedback
equations and test an intervention on each direction before claiming O2.
