# Independent evidence review

Review date: 2026-09-28. Scope: this frozen finite-context lane, its three
candidate battery receipts, mathematical contract and retained results.
Only this review file was written. No pinned producer, protocol, receipt,
shared suite, core file or other search lane was changed. No training, game,
cloud job or large download was performed.

**Conclusion:** the declared finite filter and its saved results are coherent.
The same exact local factor kernel computes a response and the posterior that
is retained for the next event. Joint dependencies demonstrably affect the
response. Positive hazards pass the narrow post-observation switching test.
These results do not establish predictive superiority, actual belief
self-observation, learned context structure, mammalian implementation, all 34
capabilities or core-replacement readiness. One concrete malformed-checkpoint
resource defect remains outside the trusted experimental fixtures.

## Equations, admission and information flow

The event graph correctly forms

```text
P(A,B,c_previous) T_h(c_next | c_previous)
    L(y | theta_c_next) 1[Q = theta_c_next].
```

The central/leaf scopes satisfy running intersection. The unobserved
deterministic output sums to one and therefore does not manufacture evidence.
The next posterior is a marginal of a settled cluster belief, not a separate
hard-coded filtering recurrence inside `Brain`. The independent recurrence in
`probe.py` is used as an oracle/control and does not supply the candidate's
answers. The binary centers, selector relation, two latent slots, likelihood,
priors and hazard values remain supplied structure.

`exact_query()` uses identity transition and unit likelihood, while
`prediction()` advances a private one-event branch without committing it.
`observe()` applies the transition and observation once from the original
retained state. The own-lane predictive trials use that distinction correctly.
The shared scalar battery's `pre_outcome_predictions` instead uses its standard
current-state `query()`; those fields are not next-event forecast probabilities
when `h>0`.

`qualify()` recomputes beliefs, separator agreement and all message equations
from actual messages before admitting the result. It does not merely trust
`converged=True`. The immutable `Memory` is replaced only after successful
completion. The read-only fixture tests cover a forged successful diagnostic,
unfinished cap, invalid events and continuation. Their presence is useful;
it is not a production security audit.

No material numerical error or future-label leakage was found in these
operations. The finite tree argument is a conditional exact-inference result.
It does not prove arbitrary loopy convergence or identify the algorithm as a
biological learning law.

Only the joint boundary and event cursor persist. The factor graph and messages
are rebuilt for each operation; individual factor patches do not each retain
their own experience record. Reusing the local operation across these problems
is a real implementation property, but is narrower than a continuously
operating hierarchy of persistent self-observing patches.

All three adapters pass their fly-transition, grouped-holonomy and joint
federation-boundary challenges. The battery leaves full capability contracts
unpassed and `core_replacement_ready=false`. In particular, O2 is genuinely
unsupported: the model has a latent world context, but no interface that reads
another patch's actual belief uncertainty and feeds back into it. Calling
`c` an observer would not change that fact.

Endpoint switching is weak evidence by itself. A latest-value rule returns the
right center after each block. More informative are the fixed ambiguous-input
and dependency interventions. For example, after `[-2,-2,+2,+2,0]`, the intact
`h=1/16` model answers approximately **+1.747336** and the reversed-sign/order
history answers **-1.747336**. Both histories have the same counts and latest
zero. The parameter/context product intervention returns **0** in both cases,
while preserving the full joint parameter marginal and context marginal.
This is a concrete causal dependence on the retained relation, not just on
the latest input or a bag of observed values.

It does not by itself exclude a last-nonzero decoder: that cheap control also
distinguishes these histories. The stronger mechanistic statement is that
selectively destroying the candidate's learned dependency changes its own
response. A claim that this is the uniquely necessary or most useful way to
solve the task would require stronger comparative evidence.

The exact symmetry check is important. Every recorded context marginal is
`(1/2,1/2)` under the exchangeable prior. Information lies in the association
between parameters and current context, not in selecting a private context
name. A raw context-label accuracy or entropy metric would misread these
results. The two supplied perfect-correlation fixtures are explicitly
representational examples, not memories acquired by a learning run.

### The exhaustive predictive task intentionally has no useful history

The producer enumerates all 32 sign sequences of length five uniformly and
predicts symbol five from the first four. Hence the last sign is independent
of every history. For any predicted mean `m`, conditional expected squared
error is exactly `m^2+4`; the optimum is the uniform predictor's `m=0`, MSE 4.
The uniform mixture likewise minimizes the reported observation log loss on
this symmetric endpoint set. This is an analytic property of the test.

| Hazard | Learned next-event MSE | Known-parameter filter MSE | Reset-parameter / uniform MSE |
| --- | --- | --- | --- |
| `0` | 6.499878 | 6.499878 | 4.000000 |
| `1/16` | 6.851796 | 6.799726 | 4.000000 |
| `1/4` | 5.238120 | 4.974832 | 4.000000 |

The last-value predictor has MSE 8. The learned model beating last value is
not a useful-learning advantage because it loses to the cheaper correct
uniform predictor. Its negative log probabilities also lose to uniform. The
outcome is evidence of overconfident persistence on this deliberately
history-independent source, not a refutation of filtering on a genuinely
persistent source. Report the whole table; do not use this mismatched task to
select a supposedly best biological hazard.

## Deviations, incomplete controls and custody boundaries

1. **The actual-stream lesion differs from frozen protocol step 4.** That
   paragraph says product of singletons, while `probe.py:124–127` uses
   `P(A,B)P(c)`. It is the cleaner selective dependency cut because it preserves
   `P(A,B)`. Product of all three singleton marginals is used only for the
   supplied correlation fixtures. Preserve and disclose the deviation; do not
   rewrite the frozen protocol or imply both lesions ran on actual streams.
2. **Not every proposed skeptical control ran.** The README correctly says
   so. In particular, this receipt does not execute the conditional-context
   preserving parameter reset `P0(A,B)P(c|A,B)`, score the eight suggested
   continuation targets, or record complete prospective performance against
   the last-nonzero and EMA controls. Those controls appear as current-answer
   comparisons for the fixed histories. Missing results cannot be inferred
   from the posterior oracle checks.
3. **The reset-parameter control is broader than a pure parameter lesion.**
   It replaces the memory by prior parameters times the current context
   marginal after each event. It removes dependencies as well as acquired
   parameter information. Symmetry makes that context marginal uniform here,
   explaining why this control coincides with the fully uniform predictor.
4. **108 is not the total solve count.** It is the number of recorded primary
   witnessed solves. Forecasts, read-only queries, histories, constructed
   fixtures and transactional checks execute additional kernel work without
   a complete per-call work journal. No total-work, learning-efficiency or
   solver-speed claim follows from this receipt. The battery's small resource
   sample is a separate bounded contract.
5. **Search receipt custody is incomplete as a standalone runtime manifest.**
   Its ten-file map is sampled after `run()` and omits imported shared
   `contract.py`. The battery receipts separately pin that shared file, but
   this does not retroactively give the earlier search a start/end source
   guard. Current source hashes and independent arithmetic agree; that is
   narrower than proving every executed dependency remained immutable during
   the original run.
6. **Original replay equality is not type-strict.** Python nested equality can
   treat JSON `true`, `1` and `1.0` as equal. The original `probe.py --verify`
   therefore should not be described as a complete schema/type mutation gate.
   The separately added [strict wrapper](verify_round.py) now uses canonical
   typed comparison, duplicate-key/nonfinite rejection, before/after source
   checks and an additional `contract.py` pin without changing this producer
   or its receipt. Its [verification receipt](verification_receipt.json)
   records a successful replay and correctly leaves original-run full custody
   unproven. I read those additions but did not rerun that wrapper or its tests.

### Concrete resource defect: rational checkpoint parsing

In `model.py:127–137`, checkpoint and weight-string lengths are bounded before
each weight is passed directly to `Fraction(w)`. A short scientific-notation
string such as `1e-1000000000` can request an enormous exact denominator during
parsing. It need not exceed either string-length bound. Thus a malformed
checkpoint can consume unbounded practical resources before normalization is
checked. **The oversized input was not executed.** This follows from the
accepted parsing path; all reviewed ordinary rational fixtures are unaffected.

Treat this version's restoration inputs as trusted experiment fixtures. A
later version should admit only a canonical integer or numerator/denominator
grammar, reject exponent/decimal forms before `Fraction` construction, bound
the digit/bit counts and validate the parsed mass and ownership atomically.
Do not fix the pinned producer in place or promote the current experimental
restore method as safe for arbitrary external input. R6 and production
replacement remain open.

## A meaningful next tiny test, not authorization to run it

The biological motivation should be a functional discriminator. A mouse study
found that prior context experience influenced hippocampal representations in
virtual navigation; that motivates testing identical ambiguous input after
different histories, without identifying this filter with the recorded
circuit. [Plitt and Giocomo, 2021](https://www.nature.com/articles/s41593-021-00816-6).

A human inference study provides a more demanding next constraint: after
feedback indicated a hidden switch, successful participants changed responses
for stimuli they had not yet encountered in the new context. That separates
inference about a shared context from independently relearning each recently
presented stimulus. It does not prove a particular neural algorithm or a
general theory of the whole brain. [Courellis and colleagues, 2024](https://www.nature.com/articles/s41586-024-07799-x).

The present candidate cannot test that behavior because it has no stimulus
identity. A minimal **new, separately frozen** component experiment could add
two observable stimulus symbols and four unknown binary response parameters
`theta_(context,stimulus)`, keeping a shared hidden context. The retained
joint would then have 32 states rather than eight. A direct central bag has
64 entries; exact rational width and arithmetic cost must be counted. Keep
the same generic factor kernel and all answer relations inside its graph.

Use these discrimination requirements rather than a new large campaign:

- Learn both two-symbol response profiles through actual observations, with
  context unobserved. Give all four unknown parameters an unrevealing prior;
  do not encode a known inverse mapping or copy a held-out answer.
- Include crossed profiles, such as one context mapping the two symbols to
  `(-2,+2)` and the other to `(+2,-2)`, with consistent sign/symbol relabelings.
  Also retain no-switch and ambiguous/no-information controls.
- After a hidden switch, expose feedback for only the first symbol. Then query
  the other symbol before it has been witnessed in the new context. Freeze
  and score that response before admitting its outcome. Treat the first
  unavoidable surprise separately from the following transfer trial.
- Compare the full learned joint with a parameter-frozen filter, separate
  contexts per stimulus, a dependency cut, latest-value and per-stimulus
  last-response controls, and an explicit known-mapping oracle. Restore the
  learned checkpoint to verify the causal effect is recoverable.
- Require independent exact posterior checks and honest uncertainty where
  the visible history does not identify a response. A query must neither
  count as evidence nor advance hidden time accidentally.

A successful result would support learned cross-stimulus context transfer in
a supplied finite model. It would still not provide actual belief
self-observation, broad reasoning, human equivalence or all-criteria readiness.
No such extension or additional run was performed in this review.

## Recommended claim

> A finite candidate uses one pinned local factor-conditioning kernel to
> compute current answers, one-event forecasts and retained joint posteriors.
> Exact independent checks validate the stated finite model. With supplied
> nonzero hazards it tracks the short switching fixture, and selectively
> removing retained context–parameter dependence changes ambiguous-input
> answers. It has no demonstrated predictive advantage on the uniform-stream
> diagnostic and no actual belief-self-observation interface. General learning,
> useful transfer, scalability and production replacement remain unestablished.

This is a substantive small implementation result and a clear limit, rather
than evidence that the entire redesign either succeeds or fails.
